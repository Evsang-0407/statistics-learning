# 统计与数据分析（Statistics & Data Analysis）

本仓库用于记录《统计与数据分析》课程的学习笔记、代码练习与相关资源。

## 目录结构

```
statistics-learning/
├── notes/        # 课程笔记（Markdown）
├── code/         # 代码练习（Python / R）
├── datasets/     # 练习用数据集
└── README.md
```

## 学习内容规划

- [ ] 描述性统计（Descriptive Statistics）
- [ ] 概率与概率分布（Probability & Distributions）
- [ ] 抽样与估计（Sampling & Estimation）
- [ ] 假设检验（Hypothesis Testing）
- [ ] 相关与回归（Correlation & Regression）
- [ ] 数据分析实战（Data Analysis in Practice）

## 使用说明

- 笔记统一用 Markdown 编写，放在 `notes/` 目录下
- 代码按章节整理，放在 `code/` 目录下
- 数据集放在 `datasets/` 目录下（注意：大文件建议用 Git LFS 或外部链接）

## 环境

- Python 3.x（建议配合 Jupyter Notebook / Pandas / NumPy / Matplotlib 使用）
